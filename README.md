# Steven’s Second Brain

个人知识与业务资料的总入口。仓库当前为公开仓库，仅存放通用导航、模板和不敏感资料。任何提交内容都可能被公众查看和复制。不要提交客户资料、报价底价、合同、个人隐私、未公开设计、密码或 API 密钥。

## 三个知识区

- [内窥镜业务](01-endoscopy-business/README.md)：维修配件、OEM/ODM、质量与外贸知识。
- [新业务探索](02-new-business/README.md)：与内窥镜无关的业务想法、研究和验证。
- [个人知识](03-personal-knowledge/README.md)：经验、读书笔记、学习与思考；私密日记不放入公开仓库。

## 使用顺序

筛选与去敏 → 放入对应 inbox → 整理为 Markdown/CSV 并保留来源 → 核对 → 归档 → 检查更改 → 提交并推送。

重要结论应标注来源、日期、适用范围和核实状态。AI生成内容默认待核实。
